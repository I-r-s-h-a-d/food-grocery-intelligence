# Food and Grocery Delivery Intelligence

Real-world Data Science project for analyzing food and grocery delivery data.

## Project Structure
- data: Raw and processed datasets
- notebooks: Google Colab notebooks
- src: Python source code
- models: Machine learning models
- dashboard: Interactive dashboard
- reports: Analysis reports

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, SQL, Streamlit, Google Colab.
